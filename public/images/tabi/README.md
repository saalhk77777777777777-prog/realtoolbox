# 타비 이스터에그 보상 사진

이 폴더에 66회 클릭 보상으로 보여줄 타비 사진을 넣어줘.

## 파일 이름
cute-tabi.png

## 사용 방법
1. 좋아하는 타비 사진을 이 폴더에 복사해.
2. 파일 이름을 정확히 cute-tabi.png로 바꿔.
3. TOOLBOX를 새로고침하고 이스터에그 버튼을 66회 클릭하면 보상창에서 사진이 표시돼.

PNG 권장. 다른 파일 형식을 쓰고 싶으면 src/easter-eggs/tabi-easter-eggs.ts의 TABI_REWARD_PHOTO 경로도 함께 변경해야 해.

사진 파일 자체는 저장소에 자동으로 생성되지 않아. 네가 고른 이미지 파일을 여기에 직접 넣어야 해. 파일이 없거나 로드에 실패하면 기본 타비 스타일 일러스트가 대신 표시돼.
